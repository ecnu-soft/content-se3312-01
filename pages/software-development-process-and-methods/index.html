2026 秋季｜54 学时：理论 36 学时，实践 18 学时

本课程围绕软件从需求到运行维护的完整生命周期，学习软件工程的基本概念、方法与工具，并探索 AI 如何参与分析、设计、编码和测试。通过贯穿学期的团队项目，你将练习把需求转化为可运行、可验证、可维护的软件，学会解释设计取舍、检查 AI 产出，并对自己的交付负责。

学习内容

模块 主要内容
软件过程与建模 软件工程、SDLC、Git 协作、UML 结构与行为建模
业务与需求 业务分析、需求获取与评审、验收条件、需求变更
设计与开发 架构与接口设计、配置管理、AI 辅助编码、团队集成
测试与质量 分层测试、持续集成、覆盖与变异测试、安全验证
运行与交付 部署与回滚、用户验收、AI4SE 前沿、答辩与复盘

课程项目

项目采用应用 Agent 开发组与测试 Agent 开发组配对协作。应用组实现应用任务与业务流程，测试组依据需求和接口开发独立测试 Agent，提出、执行并复现测试。双方持续交换版本与问题报告，完成修复和复验。

每组都需要完成需求、设计、实现、测试和运行交付。评价关注软件质量、验证依据与个人贡献，每位同学都应能够解释自己的工作。

学习与交付

  • 课堂学习：结合讲授、讨论与实践；部分模块采用翻转课堂，课前阅读指定材料并提交简短报告，课堂用项目问题检验和修正理解。
  • 阶段提交：以 Classmoji 中教师发布的任务要求与截止时间为准。代码及需求、设计、测试、运行等材料按任务要求提交，注明对应版本与验证结果。
  • 团队协作：使用 Git 分支和 PR 开展修改、评审与合并，保留个人提交、同伴反馈和处理记录。
  • AI 使用：按任务要求使用 AI，说明其参与方式，审阅并验证产出。每个人都须保有独立分析、编码和解释能力；不得向模型或仓库提交密钥及敏感数据。

考核方式

平时表现 5%＋课程项目 35%＋期末考试 60%。

课程项目分阶段提交，项目内部按团队证据 70%、个人证据 30% 评价。期末考试采用闭卷、无 AI 方式，考查基础知识与工程分析能力。具体任务及评分要求随课程发布。
